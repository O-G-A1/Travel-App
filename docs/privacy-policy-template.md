## Information and use
Voyara may process account details, trip destinations and dates, itinerary items, expenses, saved places, journal text, and uploaded trip files. Demo mode stores trip, itinerary, expense, packing, reminder, saved-place, trusted-contact, and journal data in this browser's local storage; document uploads are disabled in demo mode. With Supabase configured, account and trip information is processed by your Supabase project. Trip owners can invite collaborators by email-bound links; the invited email address, access role, and acceptance status are stored, and collaborators can see basic names of other members on that trip. Documents are stored in a private Supabase Storage bucket and opened through temporary signed links. If you request destination weather, the destination is sent to WeatherAPI.com. If you explicitly search for a map location, that search text is sent to Geoapify, and the map browser loads map tiles from Geoapify based on the viewed area. Currency conversion requests contain currency codes but no trip name. If you configure an AI provider and request assistance or an itinerary draft, your question or trip preferences are sent from the server to that provider. Consult that provider’s retention terms. No analytics are active by default.
